# VLA 논문 계보

> 작성 2026-09-10. 웹 검색으로 확인한 내용 기반. 날짜는 arXiv 최초 공개 기준.
> 모델별 실무 정보(체크포인트·VRAM·CLI)는 `docs/policies.md`에 있다.

---

## 1. 전사 — VLM 이전 (2022~2023)

### RT-1 (Google, 2022-12)
로봇 데이터 13만 에피소드로 Transformer를 학습. 액션을 **이산 토큰**으로 뱉는다.
아직 VLM이 아니다. 웹 지식이 없어서 **학습 때 본 물체·지시만** 다룰 수 있었다.

### RT-2 (Google, 2023-07) — "VLA"의 탄생
**발상의 전환.** 로봇 모델을 새로 만들지 말고, **이미 있는 거대 VLM을
그대로 파인튜닝**하자. PaLI-X(55B) / PaLM-E(12B)를 가져와
**액션을 텍스트 토큰으로 출력**하게 했다.

효과가 극적이었다. 학습 때 못 본 물체 범주를 추론하고, 새로운 지시를 해석하고,
초보적인 chain-of-thought 계획까지 했다. **웹 사전학습 지식이 로봇 제어로
전이된다**는 걸 처음 보인 것이고, 이 논문이 **VLA라는 용어를 만들었다.**

> 다만 **비공개**다. 가중치도 데이터도 없다. 이 공백이 다음 장을 부른다.

### Open X-Embodiment / RT-X (2023-10)
**데이터 층위의 사건.** 여러 기관의 로봇 데이터를 22종 embodiment,
100만+ 궤적으로 통합하고 RLDS 포맷으로 표준화했다.
**ImageNet이 비전에 한 역할**을 노린 것이고, 이후 오픈 VLA는 거의 전부
이 데이터로 학습한다.

## 2. 오픈소스화 (2024)

### Octo (2024-05)
작고 열린 범용 정책. Transformer + **확산 액션 헤드**. 규모보다
"열린 생태계"에 기여했다.

### OpenVLA (2024-06) — 오픈 VLA의 첫 표준
**7B, 완전 공개.** Prismatic VLM(Llama 2 7B + SigLIP/DINOv2) 위에
OXE 97만 에피소드를 학습. 액션은 차원별 **256-bin 이산화**.

RT-2가 보여준 것을 **누구나 쓸 수 있게** 만들었다는 게 기여다.
2024년 내내 사실상의 기준점이었다.

**하지만 세 가지 약점이 있었다** (자세한 것은 `docs/policies.md` §7):
- 액션 청킹 없음 → **A100에서 약 3Hz**
- 단순 binning → 정밀·고주파 동작에서 무너짐
- 7B인데 후속 모델들보다 성능이 낮음

## 3. 패러다임 전환 (2024-10 ~ 2025)

여기서 분야의 축이 **"VLM에 토큰 붙이기"에서 "VLM + 전용 액션 생성기"** 로 바뀐다.

### π0 (Physical Intelligence, 2024-10) — 가장 중요한 전환점
[arXiv:2410.24164](https://arxiv.org/pdf/2410.24164).
PaliGemma 3B VLM + **3억 파라미터 action expert**. 액션을
**flow matching**(확산 계열)으로 생성하고, **한 번에 50스텝 청크**를 뽑는다.

**왜 결정적인가** — 액션을 텍스트 토큰으로 욱여넣던 방식을 버리고,
**연속 액션을 위한 전용 모듈**을 VLM에 붙이는 구조를 확립했다.
멀티모달 분포를 표현할 수 있고 최대 50Hz가 나온다.
이후 GR00T, MolmoAct 2, 대부분의 대형 VLA가 이 구조를 따른다.

### π0-FAST (2025-01) — 반대 방향의 답
같은 팀이 낸 **대안**. flow matching 대신 **자기회귀 토큰**으로 돌아가되,
토큰화를 제대로 했다. **FAST** = 액션 청크에 DCT를 걸고 고주파를 버린 뒤
BPE로 압축. 기존 binning 대비 10배 압축, 학습 5배 빠름.

**"단순 binning이 문제였지 토큰화 자체가 문제는 아니었다"** 는 반박이다.

### OpenVLA-OFT (2025-02)
[arXiv:2502.19645](https://arxiv.org/pdf/2502.19645).
OpenVLA에 **액션 청킹 + 병렬 디코딩 + 연속 액션 + L1 회귀**를 붙였다.
LIBERO **76.5% → 97.1%**, 액션 생성 **26배 가속**(109.7Hz).

계보상 의미가 크다 — **구세대 설계의 어느 부분이 병목이었는지를
통제 실험으로 밝힌** 논문이다.

### GR00T N1 (NVIDIA, 2025-03)
휴머노이드 지향 2B 오픈 모델. **dual-system** 구조
(느린 VLM 추론 + 빠른 확산 트랜스포머 액션 생성).
실 로봇 + **합성 데이터**(Isaac) + 인터넷 영상을 섞어 학습.
이후 N1.5 → **N1.7**(Cosmos-Reason2 / Qwen3-VL 백본)로 진화.

### π0.5 (2025-04)
[arXiv:2504.16054](https://arxiv.org/pdf/2504.16054).
목표가 성능이 아니라 **open-world 일반화** — 학습 때 못 본 집에서 청소하기.
방법은 **이종 데이터 co-training**: 웹 VQA·검출 + 사람의 구두 코칭 +
서브태스크 라벨 + cross-embodiment + 모바일 조작 400시간.

**"아키텍처보다 데이터 구성이 일반화를 만든다"** 는 주장이다.

### SmolVLA (HuggingFace, 2025-06) — 소형화 전환
[arXiv:2506.01844](https://arxiv.org/abs/2506.01844). **450M.**
π0의 1/7 크기로 실용 성능을 낸다. **소비자 GPU에서 파인튜닝 가능**해지면서
VLA 진입 장벽이 무너졌다. 분야의 관심이 "더 크게"에서 **"충분히 작게"** 로
갈라지는 지점.

### RTC (2025-06) — 실행 층위의 문제 제기
[arXiv:2506.07339](https://arxiv.org/abs/2506.07339).
모델이 아니라 **추론 알고리즘**. 청크 경계의 불연속을 비동기 추론 +
masked inpainting으로 해결. 재학습 불필요.

계보상 의미 — **경쟁의 축이 "모델 성능"에서 "실시간 실행 품질"로 확장**됐다.

## 4. 다원화 (2025 후반 ~ 2026)

단일 SOTA가 없고 방향이 갈라지는 국면이다.

배경으로, **LIBERO는 포화 상태다.** π0.5 100%, GR00T N1.7 99%,
MolmoAct 2 97%, VLA-JEPA 96%로 상위권이 몰려 변별력을 잃었고,
평가는 LIBERO-Pro / LIBERO-Plus / RoboCasa365 같은 변형으로 옮겨갔다.

### 크로스 임바디먼트
- **X-VLA** (ICLR 2026) — soft-prompted transformer.
  하나의 파운데이션 체크포인트를 여러 로봇 도메인에 학습시키되
  embodiment별 정렬을 유지한다.

### 실물 성능 지향
- **MolmoAct 2** (Ai2, 2026-05) — Molmo 2-ER 백본 + flow matching action expert.
  **가중치·데이터·학습법 전부 공개.** 양팔 조작 지향.
  `MolmoAct 2-Think`는 **필요할 때만 depth 토큰을 예측하는 적응적 추론**을 한다.
  원본 대비 최대 37배 가속(액션 ~180ms, depth 추론 시 ~790ms).

  **주목할 수치:** Cortex AI의 제3자 **실물 양팔 파인튜닝** 평가에서
  MolmoAct 2 **0.51**, OpenVLA-OFT **0.36**, π0.5 **0.32**.
  LIBERO가 아니라 실물 평가라 의미가 다르다. 다만 제3자 단일 평가이므로
  단정은 이르다.

### 월드 모델 계열
- **VLA-JEPA**, FastWAM, LingBot-VA — 액션을 직접 예측하기 전에
  **미래 상태를 예측하는 표현**을 학습한다. LeRobot에 이미 들어와 있다.

### 리워드 모델 계열
- SARM, TOPreward, Robometer — **"잘한 행동"을 평가하는 모델**.
  RL·자동 평가로 가는 길목이고, 모방학습만으로는 못 넘는 벽을 겨냥한다.

### 반동 — "복잡하게 만들 필요 없다"
- **VLA-0** ([arXiv:2510.13054](https://arxiv.org/html/2510.13054)) —
  *"Building State-of-the-Art VLAs with Zero Modification."*
  아키텍처를 건드리지 않고도 SOTA급이 나온다는 주장.
- **VLANeXt** (2602.18532) — *"Recipes for Building Strong VLA Models."*
  새 구조가 아니라 **학습 레시피**를 정리.

> 두 논문이 같은 이야기를 한다: **최근 성능 향상의 상당 부분이
> 구조 혁신이 아니라 데이터·레시피에서 왔을 수 있다.** 건강한 견제다.

### 기타 (LeRobot 지원, 아직 정리 안 함)
EO-1, WALL-OSS(Wall-OSS-0.5), EVO-1.

### 비공개 계열
Gemini Robotics(DeepMind), Helix(Figure) 등. 가중치와 학습 데이터가 공개되지 않아
외부 재현이 되지 않는다.

## 5. 축으로 보는 계보

한 줄로 이어지지 않는다. **네 축이 따로 움직였다.**

| 축 | 흐름 |
|---|---|
| **액션 표현** | 이산 binning(RT-1/RT-2/OpenVLA) → flow matching(π0) ↔ 주파수 토큰(π0-FAST) → 양립 |
| **백본** | 전용 학습(RT-1) → 거대 VLM(RT-2 55B) → 중형(π0 3B) → **소형(SmolVLA 450M)** |
| **실행** | 단일 액션(OpenVLA) → 액션 청킹(ACT/π0) → **비동기·이음매 처리(RTC)** |
| **데이터** | 단일 로봇(RT-1) → OXE 통합 → **이종 co-training(π0.5) + 합성(GR00T)** |

**가장 중요한 관찰:** 최근 성과는 대체로 **액션 표현과 데이터 구성**에서 나왔고,
**모델을 키우는 데서 나오지 않았다.** LLM 계보와 결정적으로 다른 지점이다.
SmolVLA 450M이 실용적이라는 사실이 이걸 압축해서 보여준다.

## 7. 이 랩에서의 읽기 순서

계보 전체를 훑을 필요는 없다. **네 편이면 축이 다 잡힌다.**

1. **ACT** (2304.13705) — 청킹의 원형. 짧고 구현이 명확하다
2. **OpenVLA** (2406.09246) — 구세대의 완성형. `action_tokenizer.py`가 압권
3. **π0** (2410.24164) — 현재 표준 구조. 여기가 본체
4. **π0-FAST** — 3번의 대안. 2번과 대조하면 **"토큰화를 어떻게 해야 하는가"** 가 선명해진다

여유가 되면 **RTC**(실행 층위)와 **π0.5**(데이터 층위)를 더한다.
`docs/mpc-act-rtc.md`가 1·4번의 배경 설명이다.
