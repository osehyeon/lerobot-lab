# VLA 평가 데이터셋·벤치마크 계보

> 작성 2026-09-10. 웹 검색으로 확인한 내용 기반. 날짜는 최초 공개 기준.
> 모델 쪽 계보는 `docs/vla-lineage.md`에 있다.

계통이 셋이다. 서로 다른 문제를 푼다.

- **A. 시뮬레이션 벤치마크** — 재현 가능하고 값싸다. sim2real 격차가 대가다
- **B. 실물 데이터셋** — 학습 코퍼스이자 평가 셋업의 기준점
- **C. 실물 평가 체계** — 실물 성공률이 재현되지 않는 문제를 정면으로 다룬다

---

## 1. 전사 — RL 시대의 유산 (2019~2021)

VLA 이전, 강화학습·멀티태스크 학습을 위해 만들어진 것들이다.
지금도 쓰이지만 원래 목적은 달랐다.

### Meta-World (2019)
MuJoCo 기반 50개 조작 태스크. **멀티태스크·메타 강화학습 평가**가 목적이었다.
언어 지시라는 개념이 없다.

### RLBench (2019)
CoppeliaSim 기반 100개 태스크. 시연 데이터 자동 생성을 지원한다.

### CALVIN (2021)
**언어 조건부 long-horizon** 태스크 실행. VLA 이전 시대에
"말로 지시하고 긴 작업을 시킨다"는 설정의 표준이었다.

---

## 2. 실물 데이터셋 축 (2022~2025)

평가 벤치마크는 아니지만, **어떤 로봇·어떤 환경이 표준인가**를 정해버려서
평가 셋업 전체를 규정했다.

| 데이터셋 | 시기 | 규모 | 특징 |
|---|---|---|---|
| RT-1 dataset | 2022 | 13만 에피소드 | Google Robot. 단일 embodiment |
| **BridgeData V2** | 2023 | 60,096 궤적 | WidowX, 24개 환경. 테이블탑 조작 |
| **Open X-Embodiment** | 2023 | 200만+ 궤적 | **22종 로봇 / 21개 기관 통합.** 527 스킬. RLDS 포맷 표준화 |
| **DROID** | 2024 | 92K 궤적 | Franka FR3. **564개 씬 / 실제 건물 52곳 / 카메라 시점 1,417개** |
| AgiBot World | 2025 | 100만+ 궤적 | **양팔** 중심. 통일된 embodiment·카메라 구성 |

**OXE와 DROID의 설계 차이**가 이후 갈래를 만들었다.
OXE는 **이질적인 것들을 모아 폭**을 얻었고(로봇마다 형태가 다름),
DROID는 **하나의 플랫폼으로 통일하되 씬과 시점의 다양성**을 극단으로 밀었다.
그래서 DROID는 학습 코퍼스인 동시에 **평가 기준 셋업**이 될 수 있었고,
실제로 RoboArena가 DROID 위에서 돌아간다.

## 3. VLA 전용 시뮬 벤치마크 (2023~2024)

### LIBERO (2023) — 사실상의 표준
130개 조작 태스크를 **네 갈래(suite)** 로 나눈다. 각각이 다른 종류의 일반화를 잰다.

| Suite | 재는 것 |
|---|---|
| **Spatial** | 공간 배치 변화 |
| **Object** | 물체 중심 조작 |
| **Goal** | 목표 조건부 실행 |
| **Long (10)** | 장기 의존성 |

원래는 **lifelong robot learning**(순차적으로 새 태스크를 배우며 기존 것을 잊지 않기)
용으로 설계됐는데, 표준 평가 프로토콜이 딸려 있어서 VLA 논문의 기본 표가 됐다.

### SimplerEnv (2024) — real-to-sim
발상이 다르다. **실물 로봇 셋업을 시뮬로 재현**해서, 실물 정책을 값싸게 평가한다.
WidowX(BridgeData V2)와 Google Robot(RT 계열) 셋업을 그대로 옮겼다.
2절의 데이터셋들이 만들어놓은 표준 셋업이 있었기에 가능했다.

### RoboCasa (2024)
robosuite 확장. **사실적인 주방 씬**을 대규모로 넣고 100개 태스크,
여러 로봇 플랫폼을 지원한다.

## 4. 포화와 반작용 (2025~2026)

### 포화
LIBERO 상위권이 몰렸다 — π0.5 100%, GR00T N1.7 99%, MolmoAct 2 97%, VLA-JEPA 96%.

### LIBERO-Plus (CVPR 2026) — 견고성 폭로
LIBERO에 **통제된 섭동 7종**을 건다.

> 물체 배치 · 카메라 시점 · 로봇 초기 상태 · 언어 지시 · 조명 · 배경 텍스처 · 센서 노이즈

10,030개 태스크의 **테스트 전용** 세트다. SOTA 10종을 돌린 결과가 이렇다.

**성공률 95% → 30% 미만.**

논문이 지목한 원인 셋:
- **시각 고착** — 고정된 시각 특징에 과의존해 시점·조명 변화에 무너진다
- **운동학 추론 부족** — 로봇 구성이 바뀌면 일반화가 안 된다
- **언어를 사실상 안 본다** — 지시문이 무시되거나 거의 활용되지 않는다

### LIBERO-Pro
같은 결의 섭동 벤치마크. **의미적 견고성과 공간적 견고성을 분리해서** 측정한다.

### "What Are We Actually Benchmarking in Robot Manipulation?" (2606.04233)
LIBERO·CALVIN·SimplerEnv·RoboCasa·RoboTwin 2.0에 진단 테스트를 돌린 감사 논문.
**LIBERO와 CALVIN이 다수 진단에서 실패**한 반면,
**RoboCasa와 RoboTwin 2.0은 실패가 적었다** — 최근 성과 주장에는 훨씬 덜 등장하는데도.

## 5. 실물 평가 체계 (2025~2026)

시뮬로는 안 되고, 실물은 재현이 안 된다는 이중고에 대한 응답들이다.

### RoboArena (CoRL 2025, [2506.18123](https://arxiv.org/abs/2506.18123))
**표준화를 포기한다.** 고정된 태스크·환경을 정하는 대신,
분산된 평가자 네트워크에 **크라우드소싱**한다. 평가자는 태스크와 환경을 자유롭게 고르되,
**두 정책을 쌍으로 놓고 double-blind 비교**하는 것만 지킨다.

LLM의 Chatbot Arena와 같은 발상이다. 절대 점수를 포기하고 **상대 비교**를 얻는다.
DROID 기반 정책들을 대상으로 한다.

### RoboChallenge (2510.17950)
대규모 실물 로봇 평가.

### VLA-REPLICA (2605.20774)
**저비용·재현 가능**을 목표로 한 실물 벤치마크. 재현성 문제에 대한 직접적 응답.

### PhAIL (2605.29710)
실물 VLA 벤치마크 + 분포적 방법론.

### RoboDojo (2607.04434)
**시뮬과 실물을 하나로 묶은** 통합 벤치마크.

실물 평가 비용 문제를 "실물을 시뮬로 복제해서" 푸는 갈래. 독립적으로 진화했다.

## 8. 축으로 보는 흐름

| 축 | 흐름 |
|---|---|
| **목적** | RL 멀티태스크(Meta-World) → 언어 조건부(CALVIN) → VLA 일반화(LIBERO) → **견고성(LIBERO-Plus)** |
| **환경** | 순수 시뮬 → real-to-sim(SimplerEnv) → 사실적 씬(RoboCasa) → **시뮬+실물 통합(RoboDojo)** |
| **평가 방식** | 고정 태스크 절대 점수 → **크라우드소싱 쌍대 비교(RoboArena)** |
| **데이터 규모** | 단일 로봇 13만(RT-1) → 22종 200만(OXE) → 씬 다양성(DROID) → 양팔 100만(AgiBot) |

## 9. LeRobot에서 쓸 수 있는 것

LeRobot 문서가 시뮬 평가 대상으로 드는 것은 **LIBERO**와 **Meta-World**다.
`lerobot-eval --env.type=libero --env.task=libero_spatial` 형태로 돌린다.
π0.5·GR00T·π0-FAST 문서의 재현 수치가 모두 LIBERO 기준이다.

`allenai/vla-evaluation-harness`는 LeRobot 계열(MolmoAct2, VLA-JEPA, SmolVLA)을
모델 서버로 지원한다.
