## 1. 연구 질문

**주 질문**
> 큰 VLA에서 검증된 양자화 기법이 **소형 VLA(SmolVLA 450M)** 에서도 성립하는가?

작은 모델은 중복성이 적어 양자화 여유가 좁다. 3B~7B 대상으로 설계된 기법이
450M에서 무너진다면, 무너지는 지점과 이유가 결과가 된다.

**부 질문**
> 양자화 열화는 **평균 성공률보다 견고성에서 먼저** 나타나는가?

### 가설 H1
SmolVLA는 π0.5·GR00T 대비 동일 비트폭에서 열화가 크다.
특히 W4A4에서 격차가 벌어진다.

### 가설 H2
포화된 LIBERO에서는 양자화 손실이 거의 보이지 않지만,
**LIBERO-Plus 섭동 하에서는 원본과의 격차가 크게 벌어진다.**

> **H2의 근거:** QuantVLA는 π0.5 W4A8에서 **97.6%** 를 기록해
> FP16 원본 **97.1%** 를 넘어섰다. 양자화가 성능을 올렸다기보다
> **LIBERO가 변별하지 못한다**는 신호로 읽는 편이 타당하다.
> 이 지점이 H2의 출발점이다.

---

## 2. 대상 모델

| 역할 | 모델 | 근거 |
|---|---|---|
| **주** | SmolVLA 450M (`lerobot/smolvla_base`) | 양자화 문헌에서 주 대상으로 다뤄진 적 없음. flow matching action expert 보유. QAT까지 자원 내 가능 |
| **대조** | π0.5 3B (`lerobot/pi05_base`) | QuantVLA가 수치를 공개 → 직접 비교표 작성 가능 |

두 모델 모두 LeRobot 1급 지원이라 평가 파이프라인이 공통이다.

**확장 후보** (자원 여유 시): GR00T **N1.7**.
QuantVLA가 다룬 것은 N1.5이고 N1.7은 백본이 Cosmos-Reason2 / Qwen3-VL로 교체됐다.
LeRobot이 N1.5 지원을 제거해 미개척 상태.

---

## 3. 벤치마크

| 순위 | 벤치마크 | 역할 |
|---|---|---|
| 1 | **LIBERO 4 suite** (Spatial/Object/Goal/Long) | 기존 문헌과의 비교 가능성 확보. 필수 |
| 2 | **LIBERO-Plus** | H2 검증. 섭동 7종 하의 견고성 |
| 3 | SimplerEnv | 크로스 태스크 일반화. QuantVLA도 사용 |

실물 로봇 평가는 하지 않는다 (하드웨어 없음, 재현 불가).

**캘리브레이션 데이터:** LeRobotDataset에서 라벨 없이 추출.
QuantVLA 관행은 128배치 + 99.9 퍼센타일 활성값 클리핑 + per-channel smoothing 0.15.

## 4. 비교군

| 계열 | 방법 |
|---|---|
| 순진한 기준선 | RTN (round-to-nearest) |
| LLM PTQ 표준 | GPTQ, AWQ, SmoothQuant |
| 회전 기반 | DuQuant |
| **VLA 전용 SOTA** | **QuantVLA** |

QuantVLA가 주 경쟁 상대다. 같은 벤치마크·같은 비트폭으로 재현한 뒤 비교한다.

---

## 5. 실험 매트릭스

### 본 실험

| 축 | 설정 |
|---|---|
| 비트폭 | W8A8 → **W4A8**(주) → W4A4(한계) |
| 모델 | SmolVLA, π0.5 |
| 벤치마크 | LIBERO 4 suite, LIBERO-Plus, SimplerEnv |
| 지표 | 성공률(%), 메모리(GB), 레이턴시(ms) |

### 절제 실험

1. **부위별 정밀도** — 액션 헤드 / 비전 인코더 / LM 백본을 각각 FP 유지 시 영향.
   QuantVLA는 DiT의 **attention projection(Q,K,V,O)을 FP로 남긴다.**
   여기를 낮추면 어디서 깨지는지가 핵심 절제 항목.
2. **디노이징 스텝별 열화** — flow matching 스텝 수를 바꿔가며 오차 누적 측정.
   소형 모델에서 누적이 더 심한지가 H1의 직접 증거.
3. **캘리브레이션 데이터 구성** — 태스크 내 / 태스크 외 / 웹 데이터.
   VLA에서 무엇으로 캘리브레이션해야 하는지는 정리되지 않은 문제.
4. **섭동 종류별 민감도** — LIBERO-Plus 7개 요인 중 양자화가 특히 취약한 축 식별.

---

## 6. 통계 처리

성공률은 이산 결과라 분산이 크다. 50 에피소드 기준 표준오차가 약 ±7%p이고,
양자화 열화가 2~3%p면 노이즈와 구분되지 않는다.

- suite당 **에피소드 50개 이상**
- **시드 3개 이상**, 평균과 신뢰구간 함께 보고
- 주장하는 차이에 대해 유의성 검정 명시

## 7. 단계

| 단계 | 내용 | 산출물 |
|---|---|---|
| **P0** | 서버 환경 구축, LeRobot 설치, LIBERO 평가 재현 | FP16 기준선 수치 |
| **P1** | RTN·GPTQ·AWQ·SmoothQuant를 SmolVLA/π0.5에 적용 | 기존 기법 붕괴 지점 확인 |
| **P2** | QuantVLA 재현 | 공정 비교 기준 확보 |
| **P3** | LIBERO-Plus 평가 추가 | **H2 검증** |
| **P4** | 제안 기법 설계·검증 | 논문 본체 |

**P1이 실질적 분기점이다.** 기존 기법이 SmolVLA에서 실제로 무너지면 H1이 서고
논문의 문제 설정이 완성된다. 무너지지 않으면 주 대상을 π0.5 / GR00T N1.7로 옮기고
H2(견고성) 축으로 무게를 이동한다.

## 8. 자원

가정: **A100 40GB 1~2장.**

| 작업 | 요구 |
|---|---|
| SmolVLA PTQ + 평가 | 24GB로 충분 |
| SmolVLA QAT | A100 40GB 1장 |
| π0.5 PTQ + 평가 | A100 40GB 1장 |
| π0.5 QAT | 범위 밖 (PTQ만) |

`docs/policies.md` §9 기준. 학습이 아니라 추론 중심이라 표의 수치보다 가볍다.

**24GB 1장뿐인 경우:** SmolVLA 단독 + PTQ로 좁히고 LIBERO-Plus 분석을 깊게 판다.
**A100 80GB 다수인 경우:** π0.5를 주 대상으로 올리고 GR00T N1.7을 추가한다.

## 9. 리스크

| 리스크 | 대응 |
|---|---|
| SmolVLA에서 기존 기법이 잘 작동 → H1 붕괴 | 주 대상을 π0.5/GR00T N1.7로 전환, H2 중심으로 재구성 |
| LIBERO-Plus에서도 차이가 안 보임 | 섭동 강도를 축으로 삼아 열화 곡선 자체를 결과로 제시 |
| QuantVLA 재현 실패 | 공개 코드 확인. 없으면 SmoothQuant/DuQuant를 주 비교군으로 |
| 450M의 절대 절감량이 작다는 지적 | 절감률이 아니라 **엣지 배포 가능선과 제어 레이턴시**를 기준으로 제시 |
| LIBERO-Plus를 이미 쓴 양자화 논문 존재 | 투고 전 재확인 필요. 현재 검색 범위에서는 없음 |
